# Museu Nacional: site em HTML e CSS

Página de apresentação do Museu Nacional, feita com HTML e CSS como exercício de front-end.

## Seções

- **Capa:** abertura com a identidade do museu
- **Postagens:** vídeo de apresentação (YouTube), mapa de localização (Google Maps) e um texto sobre os 200 anos de história do museu
- **Depoimento:** relato de um visitante
- **Visita:** formulário "Faça uma visita"
- **Galeria:** galeria de fotos

## Tecnologias

- HTML5
- CSS3, com `normalize.css` para padronizar a aparência entre navegadores

## Como abrir

Não precisa instalar nada: baixe o repositório e abra o `index.html` no navegador.
